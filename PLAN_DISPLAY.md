# Отображение: рачительно к месту (план переделки, 13 ноя)

Жалоба пользователя (снимки 13 ноя): «целые колонки ради одного символа», «хоп — колонка ради одной тильды»,
фраза разъезжается по чужим колонкам, пустые подколонки висят. Цель: **ширина трека = только то, что в нём
сейчас звучит и правится; пометки — внутри ячейки, не отдельными колонками.**

## Что сейчас тратит место (по снимкам)
1. **Подколонки на всю песню.** Наложение нот хоть в одном месте проекта (или `−` / `+` subs_min) даёт трек
   из 3–4 подколонок везде, хотя в видимом паттерне нота одна.
2. **Знак = колонка.** `~` (луп / легато), `"` (фраза), `+` (fold), `^` (микротон) расширяют поле ноты или
   добавляют подполе на весь трек.
3. **Копии фраз** — настоящие айтемы на треках фразы: модель кладёт их в свободные подколонки чужих треков →
   новые колонки и «хаос».
4. **Волна-колонка** (`wave`) занимает свою ширину даже когда в ней одна нота.
5. **Пустые поля** inst / vol / fx показываются точками у всех строк, хотя заполнены в одной.

## Принципы
- **Окно, не песня.** Число подколонок, поля и ширины считаются по *видимому окну* (паттерн / секция / экран),
  а не по всему проекту. Ушёл из места с аккордом — трек снова узкий.
- **Пометки — в ячейке.** Один символ состояния — надстрочный знак / цвет / уголок в самой ячейке ноты, без
  ширины: `~` луп → тонкая волнистая линия под нотой, `"` фраза → уголок, `+` fold → точка-счётчик, `^` → цвет.
- **Поле появляется, когда в окне есть значение.** inst / vol / fx-поля трека — только если хоть одна строка
  окна их заполняет; INSERT на поле — временно раскрывает (как сейчас wave only).
- **Копии фраз не занимают колонок.** По умолчанию копии не раскладываются моделью в подколонки треков; в
  трекере видна только нота-триггер (коробка — её строки); копии — призраки в tracker 2 / по опции.
- **Приоритет при нехватке ширины:** нота > inst > vol > fx > wave; сначала сворачиваются поля, потом
  подколонки (в «+N»), трек не уже ноты.

## Шаги
1. **Подколонки по окну** (модель: sub-раскладка по [r0, r1) вида; snap держит полную раскладку, вид — свою
   выборку колонок). Самое заметное.
2. **Пометки в ячейке:** `~`, `"`, `+`, `^` — без ширины (draw DCS: ширина поля ноты фиксирована 3 знака).
3. **Поля по наличию в окне** (layout: w_inst / w_vol / nfx по видимым строкам; кэш по окну и snap.sid).
4. **Копии фраз:** P_EXT jf_phrc → модель не создаёт им подколонок у трекера (опция «phrase ghosts»: off /
   in tracker 2 / inline).
5. **wave-колонка** — только у трека, где аудио в окне длиннее строки; иначе волна в поле ноты (fill).
