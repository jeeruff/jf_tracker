# MIDI-модуль: любой контроллер — сразу в дело (план, 11 ноя)

Сейчас: вкладка midi — MIDI learn слайсера (jf_tracker_midimap.lua): цели — ручки и кнопки слайсера, режимы abs /
rel / rel64, привязки глобально (ExtState midimap). Цель плана — learn на ВСЁ, что есть в трекере, и профили
контроллеров, которые едут из проекта в проект и с компьютера на компьютер.

## 1. Learn на всё (одно правило)
- **Hover-learn**: мышь над любым слайдером / кнопкой / параметром (DSP, шапка трека, микшер, CONTROL, пульт slixer)
  + `Cmd+L` (или кнопка learn в midi) → крутнул ручку — привязано. Цель описывается словами, а не номером:
  `track:<имя или «курсор»>/vol`, `dsp:<плагин>/<параметр>`, `cmd:<действие трекера>`, `pad:<n>`.
- **Цели «по смыслу», не по треку**: «громкость трека курсора», «параметр, выбранный в DSP», «текущий паттерн
  матрицы», «пэд под курсором» — один контроллер работает в любом проекте без перепривязки.
- **Команды трекера** как цели: любая клавиша / :команда (`:patorder`, play pattern, zt, hold-note) — кнопка
  контроллера = клавиша.

## 2. Профили контроллеров (переносимые)
- Профиль = файл `Data/jf_tracker/controllers/<устройство>.json`: устройство (имя порта MIDI), привязки, режимы,
  кривые. Подключил контроллер — профиль включился сам (по имени порта); новый — пустой, learn в него.
- Слои / банки внутри профиля (кнопка-shift контроллера переключает назначение ручек: mixer / DSP / slixer / pattern).
- Импорт / экспорт профиля одним файлом (поделиться, бэкап); профиль проекта (ProjExtState) — поверх глобального,
  только где нужно отличие.
- Готовые профили-заготовки: 7i 25k, SP-404MKII (mode B), Machinedrum (jf_mdx), generic 8 ручек + 8 пэдов.

## 3. Обратная связь
- Светодиоды / кольца ручек: значение цели уходит назад на контроллер (CC / note out), если устройство умеет.
- Мягкий подхват (pickup): ручка с абсолютным значением не прыгает, пока не догонит текущее (или — scale / relative).
- На экране: hover по привязанному — подпись «CC21 ch1 · 7i 25k»; панель midi — кто на что привязан, живые значения.

## 4. Особые фичи
- **MIDI → трекер-команды**: Program Change → паттерн / секция матрицы; ноты пэдов → keyspat (уже есть) для любого
  контроллера через профиль.
- **Макро-ручка**: одна ручка → несколько целей с диапазонами и кривыми (как ★ контейнера, но глобально).
- **Запись движений**: крутишь привязанную ручку при записи — огибающая / команды в колонке (0M, 0P …) на строках.
- **Мод-матрица из контроллера**: CC как источник модуляции (через jf_modmatrix-подход: plink к параметру).
- **MIDI-монитор**: последние события порта (кто прислал, канал, CC) — для learn без гадания.
- **Фильтр / роутинг входов**: что из контроллера идёт в трек (ноты), а что только в learn (CC) — связь с панелью inputs.

## Порядок
1. Цели «по смыслу» + hover-learn + профиль на устройство (JSON, автоподключение по имени порта).
2. Pickup, подписи привязок, MIDI-монитор в панели midi.
3. Команды трекера как цели, слои / банки, макро-ручка.
4. Обратная связь на контроллер, запись движений, заготовки профилей.
