# MIDI / OSC: любой контроллер — только нативным learn REAPER (план, 11 ноя; переписан 12 ноя)

Решение 12 ноя: **своих профилей нет**. Привязки живут в REAPER: learn экшенов (reaper-kb.ini, глобально — едет
во все проекты), learn параметров FX (в проекте / цепочке), OSC — нативная поверхность (.ReaperOSC). Трекер
только **отдаёт себя в экшены**, которые REAPER умеет учить. Старая вкладка midi (свой learn слайсера,
jf_tracker_midimap.lua) — убрать после переноса её целей в экшены.

## Как трекер становится учимым
- **Экшен-скрипты в репо** (`actions/jf_tracker_<цель>.lua`, по файлу на цель, регистрируются кнопкой в трекере
  через AddRemoveReaScript). Скрипт читает `get_action_context()` → значение / разрешение / относительный режим
  (REAPER даёт это и для MIDI CC, и для OSC) и кладёт его в ExtState `jf_tracker_in` (цель, значение, счётчик).
  Трекер в кадре забирает и применяет. Ручка — «MIDI CC / OSC only», кнопка — обычный экшен.
- **Цели «по смыслу»**: слайдер под курсором в модуле в фокусе (reform scale / curve / shift…, humanizer,
  lfogen, slixer, DSP-параметр), «громкость / пан трека курсора», «текущий паттерн ±», play pattern, команды.
  Одна ручка «value under cursor» + кнопки «next / prev slider» покрывают любой модуль — reform включительно;
  плюс по экшену на частые слайдеры (reform scale, curve …) — чтобы ручка была всегда своя.
- **Нативное для нативного**: громкость / пан трека — экшены REAPER «selected track (MIDI CC/OSC only)», трекер
  держит трек курсора выделенным; FX-параметр — нативный learn (Param → Learn) с soft takeover REAPER.
- **Hover-learn**: Cmd+L над слайдером → трекер открывает список экшенов REAPER на нужном скрипте (поиск по
  имени) — шорткат ставит пользователь в нативном окне. Подпись привязки берём из reaper-kb.ini (чтение).

## OSC
- Нативная поверхность OSC REAPER: те же экшены по `/action/<id>` (значение — аргументом), громкость / пан /
  FX — стандартные адреса .ReaperOSC. Свой паттерн-файл `jf_tracker.ReaperOSC` с понятными адресами
  (`/jf/value`, `/jf/next`, `/jf/pattern`) — копия по кнопке в OSC-папку REAPER.
- Обратная связь: для нативных целей (трек, FX) — сама поверхность REAPER (MIDI-фидбэк learn, OSC-ответы).
  Для целей трекера (reform …) — нет: Lua без сокетов; позже — через JSFX-мост (MIDI out на контроллер).

## Порядок
1. Экшены value / next / prev / toggle + приём в трекере (ExtState) + reform, humanizer, DSP как первые цели.
2. Cmd+L: открыть список экшенов на цели; подписи привязок из reaper-kb.ini.
3. Цели слайсера из старой вкладки midi → экшены; вкладку midi убрать.
4. jf_tracker.ReaperOSC; Program Change → паттерн; запись движений ручки в колонку команд.
