## Главное для пользователя (его воркфлоу, 30 окт)

**Записать большой джем с флейты, потом обрамить его паттернами и другими
большими джемами с сэмплера и синтов.** Всё ниже — под это:

- Длинный джем = один большой аудио-айтем через много паттернов (не режется на
  клипы). Паттерны-регионы ложатся поверх него — разметка, а не нарезка.
- Обрамление: на других треках — паттерны из библиотеки (пулом) и другие
  длинные джемы (сэмплер, синты) — тоже целыми айтемами.
- Матрица показывает регионы-паттерны и что на каждом треке в каждом из них
  (как сейчас); monome grid работает с матрицей (регионы), клипы ему не нужны
  (grid клипы сессии не использовал — проверено 30 окт).

## Решения (30 окт)

1. **Паттерн = регион на все треки** (как сейчас), не айтем на дорожку.
2. **Копия в песню — пул** (правка в библиотеке меняет все вхождения);

3. Не понято — переформулировка ниже.
4. Клипы — убраны.

### Вопрос 3 (переформулировка)

Если варианты паттерна лежат в лейнах трека (лейн 1 звучит, 2..N — варианты),
то «запустить вариант» во время игры = сделать его звучащим лейном. Когда он
должен переключиться: **сразу**, **с начала следующего такта** или **с начала
следующего паттерна (региона)**? Предложение: с начала следующего такта,
опционально — паттерна. Если лейны-варианты не нужны (джемы и пул паттернов
важнее) — этот пункт можно отложить.

## Идея

- **=PATTERNS** — большой общий регион-библиотека (как =LIB для сэмплов): там
  лежат паттерны, по одному на вариант.
- **=START … =END** — песня. Паттерн в песне — пул-копия из библиотеки.
- **Сессия = сам трек**: варианты — другие лейны того же трека (fixed lanes REAPER).

## Геометрия айтема = параметры паттерна (из диалога с Claude, нативно для REAPER)

| что | свойство REAPER | как |
|---|---|---|
| период | длина айтема + `B_LOOPSRC` | айтем зациклен — дупинг сам, скрипт в игре не нужен |
| Евклид `e5` | k нот на n строк длины айтема | Бьёрклунд по длине айтема |
| ротация `r2` | `D_STARTOFFS` тейка | сдвиг окна источника, ноты не переписываются (MIDI — проверить) |
| полиметр | разные длины на дорожках | 5 против 8 бесплатно |
| rate `x3/2` | `D_PLAYRATE` | аудио без preserve pitch — чистый интервал (3/2 ≈ +7.02 пт); MIDI — только скорость |
| индекс `a1 b3` | имя айтема / региона | буква — группа, цифра — вариант; цепочки как order list: `a1 b3 a1*2` |
| тайм-база | Beats (position, length, rate) | геометрия следует темпу |

## Порядок (предложение)

1. Длинный джем: запись флейты через трекер (ретро-захват уже есть) → целый
   айтем; паттерны-регионы поверх, трекер показывает куски джема по паттернам.
2. =PATTERNS: регион-библиотека, `:patlib` — паттерн из песни в библиотеку и
   обратно (пул).
3. Индекс `a1` и цепочки.
4. Геометрия: Евклид / ротация / rate по свойствам айтема.
5. Лейны-варианты (после ответа на вопрос 3).
