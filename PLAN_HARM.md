# harmonizer: разрайсить (план, 26 окт 2026)

Просьба: в harmonizer — наглядное определение аккорда; определять высоту
сэмпла и ставить take-маркеры с нотой / аккордом; на нотном лейне заменить
такой «маркер» нотой — сэмпл транспонируется (take pitch).

Что уже есть (не делать заново):

| что | где |
|---|---|
| аккорды по звуку трека (хрома Goertzel, шаблоны качеств) | `:chord hear [beat]`, `ctx.chord_hear` |
| аккорды по нотам → маркеры `ch:` колонки мастера | `:chord read`, chord lane мастера |
| имя аккорда по множеству нот, обращения, /бас | `jf_tracker_chord.lua` (`CH.name`) |
| лад по нотам, ступени, JI | `jf_tracker_harm.lua` |
| аудио → MIDI-ноты (aubionotes, по команде) | `:transcribe` |

## 1. Наглядное определение аккорда — в панели harmonizer

- Полоса хромы: 12 столбиков (C … B) звука под курсором трекера: строка,
  такт или выделение. Расчёт — тот же, что у `:chord hear`, без процессов.
- Рядом — лучший аккорд и ещё 2–3 кандидата с весом. Щелчок по кандидату
  пишет его в chord lane мастера (маркер `ch:`) или в строку трека.
- Для MIDI-трека та же полоса, но по нотам: видно, почему аккорд назван так.

## 2. Высота сэмпла → take-маркер

- Определение основной высоты: автокорреляция / YIN в Lua по первым ~200 мс
  (без процессов). Для трудных сэмплов — `aubiopitch` по явной команде, как
  `:transcribe`.
- Результат — take-маркер REAPER в начале сэмпла с именем ноты («C#3»). Если
  звучит аккорд (хрома шире одной ноты) — имя аккорда («Am»). У нарезанного
  сэмпла — маркер на каждом срезе.
- Маркер нативный: виден в REAPER, переживает копирование айтема.

## 3. Нота вместо маркера: транспонирование сэмпла

Сделано 27 окт (кроме slixer): `M.marker_root` — нота аудио-ноты = маркер + транспоз; набор → `D_PITCH = нота − маркер`; транспоз к аккорду — от маркера.

- Нотный лейн показывает аудио-ноту с высотой из её take-маркера.
- Набрал на ней другую ноту: take pitch (`D_PITCH`) = новая − определённая,
  и сэмпл звучит той нотой. Для аккорда («Am» → «Cm») — сдвиг по корню.
- slixer: та же высота среза → его нота в раскладке (срез звучит в ладу).

## Порядок (предложение)

2 → 3 → 1: высота сэмпла даёт основу для транспонирования и для подсказок
harmonizer; наглядная хрома — следом.
