- Gain staging: кнопка gain в заголовке большого роутера (или :gain) — jf_tracker_probe в начале цепочки, перед каждым последовательным рядом и в конце; у ряда слева метр входа, справа выхода (L R, −60..+6 dB, зелёный / янтарь от −6 / красный выше 0), над рядом — разница dB, если ≥ 0.5. Звук не меняется. Повтор gain или закрытие роутера — измерители сняты; другой трек в роутере — переезжают. В списках DSP измерителей не видно.
- Выпадашка имени — заголовок без длинной подсказки.
- Слово режима: patternkb вкл (трекер) — УЗОРКЛАВЪ; clipkb палитры (матрица) — ОТРЫВКЛАВЪ; панели performance / actions / help / note mod — УСИЛІЕ / ДѢЯНІЯ / ПОМОЩЬ / НОТОИЗМѢНА (и в остальных письменностях).
- Выпадашка имени / заметки: текущее имя в строке ввода (янтарём), список полный; набор заменяет, BS стирает, Enter на пустом — без имени (у паттерна остаётся код).
- Палитра clipkb: Shift + клавиши клеток РАЗНЫХ паттернов — отпустил Shift: звучат вместе (копии в зону =SESSION за песней, по треку на клетку, луп); Ctrl+клавиша / Esc / Space — стоп, луп / повтор / курсор как были. render — оставить сочетание паттерном. Буквы клавиш — внизу справа клетки (подпись A1-1 сверху).
- Секция матрицы (полоса слева): щелчок — выделить её слоты (все треки), двойной — луп, Cmd+двойной — запуск с квантизацией (играет — в очередь, потом луп), ПКМ — меню (launch, show in the tracker, repeat linked, copy, loop, rename, remove). Протяжка за середину — перенос перед слотом (Opt — копия, Cmd — алиас), за верхний / нижний край — граница по слотам; черта — куда встанет. :sec [launch|show|repeat|copy|loop|move N|copyto N|aliasto N].
- ПЕРЕНОС секции (move) — новый способ (сдвиг, без копий) ещё не проверен вживую: проверить, что паттерны и items на месте, LIB не тронут.
- dd / вставка слота больше не трогают трек LIB (инструменты библиотеки с 0 стирались при удалении первых слотов).
- Выпадашки вместо строк :команды — везде, где был vim.open_prompt и предзаполненная строка: длина паттерна (16 32 64 … 1b 2b 4b), шаг, свинг, луп, темп слота, нота, ramp, fade, имена трека / инструмента / item / эффекта / аранжировки / секции / плейлиста, сохранения (вид, опции, пресет, кит, визор, кривая), папка, теги pm, drumstr, параметры сэмпла, поля макроса. Текущее — в строке (набор заменяет, BS стирает), ниже варианты, своё — набором, Enter. Строкой остались только редакторы текста: команда маркера и текст плейлиста.
- \ k — режимы клавиатуры: m ноты, p patternkb, c clipkb (палитра откроется сама, фокус в матрицу); (on) у включённого.
- Меню матрицы (кнопка menu / \ в матрице): сверху — queue, go here, undo …; остальное в подменю pattern … / slot … / block … / section … / view … / move …. В section … — меню секции слота, секция из выделенных слотов (выпадашка имени), секция из time selection.
- step next — только внутри паттерна курсора (вне паттерна — не дальше 4 тактов); дальше — шаг 1, без прыжков на объекты за песней.
- automation + modulation — одна вкладка automation со страницами params / curve / mod / shape (+ item при открытом automation item). M — mod (бывшая вкладка modulation: матрица LFO / ACS / link, клики, колесо, клавиши те же), L — shape (бывшая lfo / curves: генератор формы точками), C — curve, P — params. Вкладка modulation спрятана (один раз), Ctrl+W g u / :pane modulation / метки mm ведут на страницу mod.
- Параметры в DSP / SLIDER: ~ — автоматизирован, ≈ — модулирован (было %). Свободный такт с содержимым — «?» и «unnamed - n» янтарём; n — первым следующий свободный код (новый паттерн из того, что в такте), дальше имена паттернов (то же имя — связанный повтор).
- drumrs5k: пэды всегда сеткой 4 × 4 (пустые места — тусклые рамки), справа карта всех 128 пэдов кубиками 4 × 32: занятые — голубые, выбранный — янтарь, видимое — рамкой; клик по карте — туда.
- drumrs5k карта кубиков: жёлтый — выбранный (семплер справа), оранжевый — занятый, серый — пустой, красный — выключен, мигающий зелёный — соло. Щелчок по кубику — выбрать пэд (страница к нему); Opt+щелчок — mute, Shift+щелчок — solo (повтор — все включены); то же на самих пэдах.
- Имя свободному такту, если оно уже у паттерна (B1): вопрос — n: оставить ноты новым паттерном (B3 …, по умолчанию), l: связанный повтор B1 (клетки заменятся его содержимым, синхронизация от B1).
- drumrs5k: кубик = нота MIDI, снизу вверх по 4 (ряд — 4 ноты, черта — октава), сетка 4 × 4 — окно из 16 нот снизу вверх; пэд на кубике своей ноты, пустые ноты — рамки с именем; окно — с нижнего пэда, без пэдов — с базовой октавы.
- Опция base octave (C0..C6, по умолчанию C3): слайс 1 / первый пэд при «слайсы → drumrs5k» на её C, клавиатура стартует с этой октавы ([ ] двигают как раньше). Было C4.
- Enter на номере свободного такта (список паттернов): у строки слота, без =SESSION; паттерн той же длины — такт сам становится им (связанный, содержимое от оригинала), как l; другой длины — повтор вставляется, как раньше.
