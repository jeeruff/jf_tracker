## Нарезка и lib
- [ ] Вставить одну ноту инструмента несколько раз подряд (каждая обрезает предыдущую) — в lib НЕ появляются новые записи
- [ ] То же со слайсами q…p подряд — один слайс = одна запись в lib
- [ ] Растянуть ноту (`=`, `Txx` или Option+край мышью) — всплывает вопрос: Enter = уникальная, `a` = применить ко всем связанным
- [ ] Панель item (справа во вкладке item): громкость / транспонирование меняют ВСЕ ноты инструмента, у нот остаются свои значения
- [ ] `bsync` в шапке lib: сэмпл длиной в N долей; колесо в строке beatsync меняет N; вставка там, где другой темп — растягивается под него
- [ ] Учтите: уже стоящие ноты подгоняются под темп только при включении / смене N, не сами при смене темпа

## Превью и запись
- [ ] Кнопка `preview` (бывшая select): клик — вкл / выкл, правый клик — режим full / hold / первая секунда
- [ ] full: играет до конца item, Esc глушит; hold: играет, пока держите кнопку мыши на строке lib
- [ ] Во время превью на волне в модуле item бежит янтарный плейхед
- [ ] Shift+нота с клавиатуры и с MIDI-клавиатуры — тоже с плейхедом (и на слайсе, и на исходном сэмпле)
- [ ] Трек на записи (R) с jf_rec, INSERT: Shift+нота / Shift+MIDI — только звук, НИЧЕГО не пишется
- [ ] Браузер, кнопка `sync`: пока проект играет, файл стартует с начала следующего такта
- [ ] Проигрывание, начатое до `=END`, останавливается на нём; запущенное за `=END` — нет

## Вид
- [ ] Темы (options → theme или `:theme`): reaper, modus-vivendi, modus-operandi, gruvbox, catppuccin, mono
- [ ] mono: тусклый текст читается; рамка INSERT и слово INSERT в статусе красные; цвета треков в шапках остались
- [ ] Цвет шапки (ячейка `hdr`): off → line → header → full
- [ ] Выделенный в REAPER трек — колонка чуть светлее
- [ ] Линейка (options → timeline ruler): off / beats / time / both, стоит СЛЕВА от номеров шагов
- [ ] Линия курсора начинается от края полос регионов, через линейку; опция cursor line: top / bottom / off
- [ ] Границы модулей 2 px, нигде нет выступающих уголков и разрывов (матрица | трекер сквозь статус и подсказки, эффекты | DSP, вкладки сверху)
- [ ] `=START` / `=END` на линейке трекера — цветом маркеров как на таймлайне
