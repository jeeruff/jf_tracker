# Проверить (jf_tracker, 8 окт)

## Session / клипы
- [ ] Tab — клипы ↔ трекер; в фокусе клипов QWERTY запускает клипы, хинт-бар снизу меняется на clip mode
- [ ] f — метки на клипах и кнопках сцен; метка клипа = запуск, метка сцены = вся сцена
- [ ] `>` в углу клипа — запуск; красный `o` под последним клипом — запись (пока пишет весь трек, не лейн)
- [ ] два клипа на двух лейнах одного трека играют вместе
- [ ] выбор клипа — трекер показывает ноты клипа на его треке
- [ ] follow-буква клипа (a / клик): l n p f r s
- [ ] рамка фокуса трекера не рвётся на клипах; опция module gap 0..20 px

## Роутер / DSP
- [ ] кнопка router в DSP: клик — вкл/выкл, Shift+клик — большой роутер (zR)
- [ ] большой роутер: браузер переключается на вкладку fx, бросок эффекта в роутер
- [ ] слайдеры параметров в большом роутере; двойной клик по параметру — сброс на дефолт
- [ ] ReaEQ: тянутся точки, а не модуль; кнопка P/G (параметры / график)
- [ ] `/` в DSP — поиск по добавленным эффектам и параметрам, Enter — фокус
- [ ] `af` — добавить эффект; `aF` — take fx на слайс под курсором (в списке слайсов зелёный fx)

## Инструменты / браузер
- [ ] список слайсов виден всегда
- [ ] браузер: Enter — в инструменты; Opt+Enter — файл слайсом в выбранный инструмент (glue вживую не проверен!)
- [ ] слайсинг в INSERT не перескакивает на другой инструмент
- [ ] f-метки на параметрах item (volume, pan, transpose …) — прыжок к параметру
- [ ] панель rec / item / automation по умолчанию над DSP (options: top panel position)

## Шапки / ширина
- [ ] effects (кнопка у sess) — строка эффектов и сендов под шапками, f-метки
- [ ] опция hdrinfo — инструменты, инсерты, сенды в шапках
- [ ] Cmd + горизонтальное колесо — сворачивание колонок по одной
- [ ] which-key — всплывашка у курсора после d y c g z …
