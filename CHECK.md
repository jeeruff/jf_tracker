# jf_tracker — что проверить (3 окт 2026, версии 0.5.65–0.5.68)

Всё ниже сделано и прошло тесты на заглушках, но вживую в вашем проекте не
проверялось (инъекции клавиш в живой трекер запрещены). Отмечайте `[x]`.

## Нарезка и lib
- [ ] Вставить одну ноту инструмента несколько раз подряд (каждая обрезает предыдущую) — в lib НЕ появляются новые записи
- [ ] То же со слайсами q…p подряд — один слайс = одна запись в lib
- [ ] Растянуть ноту (`=`, `Txx` или Option+край мышью) — всплывает вопрос: Enter = уникальная, `a` = применить ко всем связанным
- [ ] Панель item (справа во вкладке item): громкость / транспонирование меняют ВСЕ ноты инструмента, у нот остаются свои значения
- [ ] `bsync` в шапке lib: сэмпл длиной в N долей; колесо в строке beatsync меняет N; вставка там, где другой темп — растягивается под него
- [ ] Учтите: уже стоящие ноты подгоняются под темп только при включении / смене N, не сами при смене темпа

## Превью и запись
- [ ] Кнопка `preview` (бывшая select): клик — вкл / выкл, правый клик — режим full / hold / первая секунда
- [ ] full: играет до конца item, Esc глушит; hold: играет, пока держите кнопку мыши на строке lib
- [ ] Во время превью на волне в модуле item бежит янтарный плейхед
- [ ] Shift+нота с клавиатуры и с MIDI-клавиатуры — тоже с плейхедом (и на слайсе, и на исходном сэмпле)
- [ ] Трек на записи (R) с jf_rec, INSERT: Shift+нота / Shift+MIDI — только звук, НИЧЕГО не пишется
- [ ] Браузер, кнопка `sync`: пока проект играет, файл стартует с начала следующего такта
- [ ] Проигрывание, начатое до `=END`, останавливается на нём; запущенное за `=END` — нет

## Ноты с удержанием (0.5.69)
- [ ] NORMAL, `M`: слой пианино — верхний ряд и цифры звучат, остальные клавиши — Vim; `M` / Esc — выкл
- [ ] Cmd+нота (INSERT или слой пианино): держите — курсор бежит вниз в темпе; отпустили — нота нужной длины
- [ ] Во время удержания `j` / `↓` добавляют шаг, Esc отменяет
- [ ] Cmd+Shift+нота — сэмпл растянут на удержанную длину (питч тот же)
- [ ] То же на нарезанном инструменте (q…p = слайсы)
- [ ] ⌘+цифра в NORMAL (без слоя пианино) по-прежнему выбирает слот lib

## Блок трека в DSP
- [ ] Первый слева блок DSP — выбранный трек на его цвете: R I M S, ph (фаза), FX (обход цепочки), vol / pan тянутся мышью
- [ ] `in` — клик открывает меню входа (моно, стерео, MIDI все); `out` — клик вкл / выкл master send
- [ ] `routing` (и строки send) открывают окно маршрутизации REAPER этого трека

## Скопы (вернули)
- [ ] options → track scopes (или `:scopes`): в шапке каждого трека строка-осциллограф, вкладка master снова показывает анализатор
- [ ] выключение снимает jf_tracker_scope со всех треков и с мастера (там сейчас висит старый мост — он и снимется)

## Сшивка слайсов

- [ ] Клавиши: m — слой пианино (NORMAL), M (Shift+m) — mute; trim справа в шапке трека

## Ячейки и lib (последнее)

- [ ] Цвет шапки (ячейка `hdr`): off → line → header → full
- [ ] Выделенный в REAPER трек — колонка чуть светлее

- [ ] Линия курсора начинается от края полос регионов, через линейку; опция cursor line: top / bottom / off

- [ ] Shift+клик по `trim` — огибающие в трекере вкл / выкл (старое поведение)
- [ ] ПКМ по `trim` — вкладка modulation, страница params на этом треке: все параметры, ENV / ACT / ARM / PTS / MOD / значение
- [ ] params: Enter / клик по ENV создаёт огибающую, повтор прячет; a — arm, b — active; m — LFO на параметр, второй m — строка в матрице
