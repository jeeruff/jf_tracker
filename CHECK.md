## Нарезка и lib
- [ ] Вставить одну ноту инструмента несколько раз подряд (каждая обрезает предыдущую) — в lib НЕ появляются новые записи
- [ ] То же со слайсами q…p подряд — один слайс = одна запись в lib
- [ ] Растянуть ноту (`=`, `Txx` или Option+край мышью) — всплывает вопрос: Enter = уникальная, `a` = применить ко всем связанным
- [ ] Панель item (справа во вкладке item): громкость / транспонирование меняют ВСЕ ноты инструмента, у нот остаются свои значения
- [ ] `bsync` в шапке lib: сэмпл длиной в N долей; колесо в строке beatsync меняет N; вставка там, где другой темп — растягивается под него
- [ ] Учтите: уже стоящие ноты подгоняются под темп только при включении / смене N, не сами при смене темпа

- [ ] Во время превью на волне в модуле item бежит янтарный плейхед
- [ ] Shift+нота с клавиатуры и с MIDI-клавиатуры — тоже с плейхедом (и на слайсе, и на исходном сэмпле)

## Блок трека в DSP
- [ ] Первый слева блок DSP — выбранный трек на его цвете: R I M S, ph (фаза), FX (обход цепочки), vol / pan тянутся мышью
- [ ] `in` — клик открывает меню входа (моно, стерео, MIDI все); `out` — клик вкл / выкл master send
- [ ] `routing` (и строки send) открывают окно маршрутизации REAPER этого трека
