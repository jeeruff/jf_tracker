# План живых прогонов jf_tracker (10 окт)

Цель: клавиши в NORMAL и INSERT делают ровно то, что обещают, и **не рождают
мусор** в проекте (items нулевой длины, ноты вне item, лишние треки, тронутый
LIB). Пользователь ловил по 5 багов за вечер, просто вписывая items — здесь то
же самое, но повторяемо, с дампом проекта до / после и откатом через `u`.

## Как это устроено

- `tests/live.py` — драйвер: клавиши через ExtState `inject` (веб 8080), после
  каждой ждёт `inject_ack` (режим, фокус, строка, трек, сообщение). Трекер
  исполняет инъекцию **только в песочнице** — переключил пользователь вкладку,
  прогон останавливается с `REFUSED`.
- `tests/live_dump.lua` — снимок проекта в `tests/shots/live_dump.txt`
  (треки, items, MIDI-ноты, огибающие, automation items, регионы, вершина undo).
- Каждый сценарий: `reset()` → действия → `Dump(dump())` → проверки → в `run()`
  автоматически `invariants` и `rewind()` (undo до «jf_tracker sandbox») и сверка
  с базой `tests/shots/live_base.txt`.
- Запуск: новая вкладка (40859) → `REAPER -nonewinst tests/sandbox_setup.lua` →
  `bash tests/restart.sh` → `python3 tests/live.py base` → `python3 tests/live.py run all`.
  Отчёт — `tests/shots/live_report.md`. Ошибки кадра — ExtState `err` и
  `REAPER/jf_tracker_debug.log` (ERROR …), драйвер их подхватывает.
- Перед прогоном в REAPER не должно быть модальных окон (Project Load Warning,
  сплэш): при них defer-скрипты гибнут молча. Проверка: `swift wins.swift`
  (список окон REAPER) или просто глазами.

## Песочница (sandbox_setup.lua), 120 BPM, LPB 4 → строка = 0.125 с

| трек | содержимое | строки |
|---|---|---|
| A drums | amen 0–2.0 с (D-4 resample), snare 0.375–0.875 (C-3, 2-я подколонка), hat 2.5 (offs 0.7), muted 3.0–4.0 | amen 0–16, snare 3–7, hat 20, muted 24–32 |
| B lanes | 2 fixed lanes: lane0 0–1.0, lane1 0.5–1.5 | 0–8, 4–12 |
| M synth | MIDI item 2.0–6.0 (loop источника 1 такт): C-4 qn4 1qn, E-4 qn4 2qn, G-4 qn5 короткая, D-4 qn6.125 (delay) | item 16–48; ноты 16, 16, 20, 24+delay |
| DEPOT | заглушён, 1 item — **не показывается, не меняется** | — |
